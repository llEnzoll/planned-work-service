# Сервис управления плановыми работами

## Назначение

Сервис управления плановыми работами предназначен для учета,
планирования и контроля выполнения различных плановых технических работ.

Приложение позволит заранее создавать работы, указывать дату,
продолжительность и статус, а также контролировать их согласование.

## Целевая аудитория

Целевыми пользователями являются:

- специалисты технических служб;
- системные администраторы;
- руководители подразделений;
- сотрудники организаций, отвечающие за планирование работ.

## Предметная область

Предметная область проекта связана с планированием и контролем
регламентных и технических работ.

Плановая работа может иметь название, дату выполнения,
продолжительность, статус и информацию о согласовании.

В дальнейшем сервис будет использоваться для хранения данных
о работах и управления ими через веб-интерфейс.

## Основные сущности

- Плановая работа;
- Пользователь;
- Статус работы;
- Согласование;
- Подразделение.

## Основные функции

- создание и планирование работ;
- проверка статуса плановой работы;
- проверка согласования работы;
- контроль продолжительности работы;
- просмотр запланированных работ;
- изменение статуса работы.

## План развития

На следующих этапах планируется:

- расширение консольной версии приложения;
- добавление коллекций, циклов и функций;
- реализация основных сущностей в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация регистрации и авторизации пользователей;
- добавление CRUD-операций;
- разработка REST API;
- добавление автоматизированных тестов;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
